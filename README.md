# Vector-databases

A project focused on semantic search for course and course section descriptions. It explores the use of text embeddings and vector databases to retrieve relevant content based on meaning rather than exact keyword matches.

The repository contains Jupyter notebooks covering dataset preparation, semantic search implementation, and experiments with different approaches, including BERT and Pinecone.

## Overview

Semantic search enables the retrieval of relevant content even when the query does not contain the exact words used in the course description.

The project focuses on:

- Preparing and loading course and course section datasets.
- Exploring different approaches to generating text embeddings.
- Using Pinecone as a vector database for storing and searching embeddings.
- Implementing semantic search with BERT-based model.
- Improving search quality through experiments with different datasets and approaches.
